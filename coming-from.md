# Coming from Deluge or ruTorrent

Fleet does not load Deluge `.egg` plugins or ruTorrent PHP plugins. The same jobs are covered by Fleet itself or by official extensions. Install those packages from **Extensions** (Official bucket), then open the repository if you need details.
